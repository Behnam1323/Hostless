HOSTLESS VLESS + WebSocket

1. Push/import the repository with these files at repository root.
2. In Hostless choose Docker.
3. Leave PORT unset: Hostless supplies PORT automatically.
4. Deploy.
5. The runtime log should show:
   Configuration OK.
   Starting Xray...
   Xray ... started

v2rayNG:
Address: your-app.hostless.app
Port: 443
Protocol: VLESS
UUID: a9359e2d-3c7f-49c4-a4ea-f90249c5269a
Network: WebSocket (ws)
Path: /api/ws
TLS: ON
SNI: your-app.hostless.app
Host: your-app.hostless.app
ALPN: http/1.1
Flow: empty

Do not use XHTTP or /xhttp/ in this version.
Hostless terminates HTTPS and forwards the WebSocket connection to Xray.
